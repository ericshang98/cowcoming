## 六种形态与双端回应：本轮产品定义

Eric 明确：每个既定阶段使用不同提示词，JEV 选择少量基础动作中的一个；机械臂执行对应基础动作，同时绑定的 WORK 页面从该动作衍生、提前规划且骨骼支持的动画库中随机选择一个软件角色动作。JEV 不临时生成软件动画，随机选择不能跨越基础动作语义或阶段候选范围。同一次回应记录两端状态与最终动画变体，切换视图和重复事件不重新抽取或执行。

Eric 本轮明确推翻“六档礼貌客服”的表达：角色必须多说骚话和离谱的话，六种人格不能只是语气轻重不同。小牛是脑子没开机的呆萌怪，仍优先无声动作和短音；普通牛来是刚会说话就开始吹牛的草根牛；骚牛是自恋、会撩、欠夸的戏精；硬牛是实际配合但死不认服软的杠精；仙牛是一本正经装神、总被现实拆台的修仙家；暗黑牛是被困在桌面上的中二魔王。进化强化人格，不把仙牛和暗黑牛写成鸡汤导师或沉默保镖。JEV 与 LLM 分别使用同形态的动作偏好和语言提示词；非小牛默认一至两句接梗与反转，取消旧版机械字数上限。具体阶段提示词、基础动作映射、每 N 轮完整会话评估、语言节奏和验收，以飞书及 [产品快照 §5.2](product/spec.md#52-展示-ip牛来的形态与交互内容) 为唯一详细定义；这些是首版目标，不是当前代码已经实现的行为。

代码核对基线为 `1d7a4fc`：`src/evolution.mjs` 的六节点关系符合本轮定义，但独立形态资源仍未绑定；`src/voice-interactions.mjs` 会选择完整长句，还没有小牛语言限制；`Character.jsx` 还未实现阶段与基础动作共同约束的衍生动画抽取。主分支新增实时设备接口已合入；网页发起的交互已按 commandId 关联文本、动作和完成回执。真实 JEV／LLM 提供商、机械臂和阶段资源仍需现场接入验收。未挂载的 `src/hardware/core.mjs` 旧模板和演示计数不可当作正式进化规则。

World 的 27 星光与 mama 彩蛋继续独立保存，不作为形态进化条件，小牛也不绕过该音频锁。首个工程闭环应验证一个基础动作从阶段提示词、JEV 选择到双端执行回执的过程，再扩展各形态动画库及真实会话进化评估。
