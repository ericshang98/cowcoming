# 项目现状与交接

记录日期：2026-09-23。产品依据：飞书修订 106；后续开发须核对更新。

## 已确认的产品方向

- 这是面向多 IP 的可复用软硬件互动系统；牛来是第一个 IP，不把所有能力写死在牛角色上。
- 现阶段原型硬件是机械臂、可转动的头部和头部摄像头。其他硬件支持需要单独验证。
- 第一版不依赖大模型生成回答；使用预设行为、台词、音频与结构化选择。连续跟随、运动边界和物理安全由确定性本地逻辑负责。
- 形态是可分支的进化树，不是固定三阶段 / 四阶段。普通牛、幼年牛、成年牛、硬牛等候选形态的父子关系和解锁条件仍需产品确认。
- IP、形态、硬件适配分开；切换形态须同步匹配该形态的 3D 资源和行为资源，不能资源未就绪却显示切换成功。
- 文档 §3.3 推荐网页 → 云端认证会话 / 配对 → 本地电脑主动 WSS 连接 → 硬件。短时一次性配对码、设备授权、控制租约、状态回执、断线和停止处理均属于待实现的协议约束。
- “请求已接收”不等于“动作已完成”。未配对、电脑在线但硬件未就绪、可控制、运行中、停止、失联、故障需要准确区分。恢复连接不能重放过期动作。
- 摄像头跟踪 ID 不是人员身份，不凭外观推断身份或性别。
- 最新 §3.3.5 要求把 WORK 整页替换为成长控制台，模型、动作、音频和进化配置优先形成保存在本机的能力包；本机会话负责状态写入，云端负责轻量同步。角色 GLB 本地化与 AI 推理本地化是两回事，不能据此承诺完整离线或零延迟。

具体定义、状态与例外以完整产品文档为准。这一页帮助定位，不能替代原文。

## 当前实现和边界

本仓库初始代码从已有网页原型提取，包含 React / Vite、Three.js 场景、牛模型和嘴型 / 跟随行为，以及旧模板的窗口、作品、联系等页面。

**这是网页交互原型。仓库当前没有实现云端配对服务、本地硬件连接器、机械臂驱动或完整成长树。** 不要将已有的视觉动画解释成真实硬件控制，也不要默认作品集、简历等旧模板内容属于牛来的产品需求。

修订 106 在建仓库期间新增了成长控制台及本地导入能力描述，其中“当前前端支持”的表述尚未在本仓库初始代码中验证：本次导入的是与当前已核验线上构建一致的源码，仍有 `src/pages/Portfolio.jsx` 旧 WORK 页面。不要把文档描述当成这份代码已完成该功能的证据；后续应核对对应实现和提交，再更新此状态。

- `src/scene/`：3D 场景、角色、牛模型控制、运动逻辑。
- `src/components/MouthPreview.jsx`：嘴型预览相关界面。
- `tests/behavior.test.mjs`、`tests/mouth.test.mjs`：已有的逻辑测试。
- `.env.example` 中聊天 / 联系接口默认留空。设置 `VITE_*` 会将值编入前端；不能放 Token。
- `public/_headers` 和 `robots.txt` 当前禁止搜索引擎收录，作为原型状态保留。
- 来源说明和原始评审放在 `docs/provenance/`，其中的历史验证不能冒充当前验证。
