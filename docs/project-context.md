## 产品与界面

- 项目名 **Cowcoming**：基于 JEV 决策模型的可进化 AI 宠物；项目主体是多 IP 软硬件互动系统，牛来是当前展示 IP。飞书中的“系统名称尚未确定”被 Eric 本次命名取代。
- About 保留左侧可互动的牛来大模型、右侧项目介绍与玻璃卡片。模型点击招手、拖动转身、鼠标跟随；手机模型与内容顺序滚动；键盘、暂停和加载失败有对应处理。
- Home 是牛来互动入口：跟随、拖动、挥手、预设语音与嘴型。Mama 由 World 集齐 27 个星光解锁并循环播放，声音与暂停设置生效。
- World 替代 IDEA52 的用户可见名称。以真实移动靠近收集星光，地图只设置目标，收集记录保存在浏览器。它是网页探索玩法，不是真实硬件进化回执。
- WORK 保留大模型与原页面视觉，左侧和树图现在支持六形态手动切换；左下角新增进化设置，原暂停位改为重置。先前将整页扩成成长控制台的方案已被 Eric 撤回，不应从飞书旧段落重新实施。
- Eric 指定的完整树为：小牛 → 普通牛来，然后分为骚牛 → 仙牛、硬牛 → 暗黑牛。WORK 显式开放六节点作为用户控制，点击切换逻辑形态并进入手动模式；路线按钮只浏览列表。底层旧预览工具仍保留可传入 revealed 列表的能力，不能把其默认值误当当前 WORK 门禁。各节点新模型仍待提供，主舞台使用明确标注的参考模型。右侧观察面板包含示例感知与动作说明；没有真实硬件连接。
- VOTE US 是黑客松支持页，队伍为 23 号“犇犇”。保留目前的投票位状态，不编造真实投票链接、计票或成功反馈。
- 支持中/英文切换，并在浏览器保存选择。不要绕过翻译层在另一台电脑重新维护单独版本。
- 终端改为 JEV 说明入口。旧模板仍有部分资源和未使用页面，不能当作 Cowcoming 的正式产品内容。

## 六种形态与双端回应：本轮产品定义

Eric 明确：每个既定阶段使用不同提示词，JEV 选择少量基础动作中的一个；机械臂执行对应基础动作，同时绑定的 WORK 页面从该动作衍生、提前规划且骨骼支持的动画库中随机选择一个软件角色动作。JEV 不临时生成软件动画，随机选择不能跨越基础动作语义或阶段候选范围。同一次回应记录两端状态与最终动画变体，切换视图和重复事件不重新抽取或执行。

Eric 本轮明确推翻“六档礼貌客服”的表达：角色必须多说骚话和离谱的话，六种人格不能只是语气轻重不同。小牛是脑子没开机的呆萌怪，仍优先无声动作和短音；普通牛来是刚会说话就开始吹牛的草根牛；骚牛是自恋、会撩、欠夸的戏精；硬牛是实际配合但死不认服软的杠精；仙牛是一本正经装神、总被现实拆台的修仙家；暗黑牛是被困在桌面上的中二魔王。进化强化人格，不把仙牛和暗黑牛写成鸡汤导师或沉默保镖。JEV 与 LLM 分别使用同形态的动作偏好和语言提示词；非小牛默认一至两句接梗与反转，取消旧版机械字数上限。具体阶段提示词、基础动作映射、每 N 轮完整会话评估、语言节奏和验收，以飞书及 [产品快照 §5.2](product/spec.md#52-展示-ip牛来的形态与交互内容) 为唯一详细定义；这些是首版目标，不是当前代码已经实现的行为。

代码核对基线为 `1d7a4fc`：`src/evolution.mjs` 的六节点关系符合本轮定义，但独立形态资源仍未绑定；`src/voice-interactions.mjs` 会选择完整长句，还没有小牛语言限制；`Character.jsx` 还未实现阶段与基础动作共同约束的衍生动画抽取。主分支新增实时设备接口已合入；网页发起的交互已按 commandId 关联文本、动作和完成回执。真实 JEV／LLM 提供商、机械臂和阶段资源仍需现场接入验收。未挂载的 `src/hardware/core.mjs` 旧模板和演示计数不可当作正式进化规则。

World 的 27 星光与 mama 彩蛋继续独立保存，不作为形态进化条件，小牛也不绕过该音频锁。首个工程闭环应验证一个基础动作从阶段提示词、JEV 选择到双端执行回执的过程，再扩展各形态动画库及真实会话进化评估。

## 能力边界

当前交付仍是 React / Vite / Three.js 网页原型。没有已验收的云端配对、本机连接器、真实摄像头跟踪、机械臂驱动或 JEV 在线推理闭环。模型动画与预设语音不代表真实硬件执行；预览形态不代表训练模型或完成真实成长。

首版动作方向为基础动作的结构化选择与预编排软件衍生动画，阶段适配语言由独立 LLM 或预设素材提供；连续跟随、限位、停止和故障保护由确定性控制负责。请求接收不等于动作完成。IP、形态、硬件能力分别管理。
