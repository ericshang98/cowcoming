# 项目现状与交接

更新时间：2026-09-23。飞书快照已同步为修订 111，来源与哈希见 `docs/product/source.json`。本页记录会话中明确的新决定和当前代码状态；不要把旧文档中的规划当作已实现功能。

## 产品与界面

- 项目名 **Cowcoming**：基于 JEV 决策模型的可进化 AI 宠物；项目主体是多 IP 软硬件互动系统，牛来是当前展示 IP。飞书中的“系统名称尚未确定”被 Eric 本次命名取代。
- About 保留左侧可互动的牛来大模型、右侧项目介绍与玻璃卡片。模型点击招手、拖动转身、鼠标跟随；手机模型与内容顺序滚动；键盘、暂停和加载失败有对应处理。
- Home 是牛来互动入口：跟随、拖动、挥手、预设语音与嘴型。Mama 由 World 集齐 27 个星光解锁并循环播放，声音与暂停设置生效。
- World 替代 IDEA52 的用户可见名称。以真实移动靠近收集星光，地图只设置目标，收集记录保存在浏览器。它是网页探索玩法，不是真实硬件进化回执。
- WORK 保留大模型与原页面视觉，现为进化路线预览和全屏树图。先前将整页扩成成长控制台的方案已被 Eric 撤回，不应从飞书旧段落重新实施。
- Eric 指定的完整树为：小牛 → 普通牛来，然后分为骚牛 → 仙牛、硬牛 → 暗黑牛。当前 `revealedForms` 只开放前两个节点，未揭示节点遮罩且不可通过预览绕过；浏览不解锁节点。各节点新模型仍待提供，主舞台使用明确标注的参考模型。右侧观察面板包含示例感知与动作说明；没有真实硬件连接。
- VOTE US 是黑客松支持页，队伍为 23 号“犇犇”。保留目前的投票位状态，不编造真实投票链接、计票或成功反馈。
- 支持中/英文切换，并在浏览器保存选择。不要绕过翻译层在另一台电脑重新维护单独版本。
- 终端改为 JEV 说明入口。旧模板仍有部分资源和未使用页面，不能当作 Cowcoming 的正式产品内容。

## 能力边界

当前交付仍是 React / Vite / Three.js 网页原型。没有已验收的云端配对、本机连接器、真实摄像头跟踪、机械臂驱动或 JEV 在线推理闭环。模型动画与预设语音不代表真实硬件执行；预览形态不代表训练模型或完成真实成长。

首版方向仍为预设行为与台词、结构化选择；连续跟随、限位、停止和故障保护由确定性控制负责。请求接收不等于动作完成。IP、形态、硬件能力分别管理。

## 当前代码入口

- `src/App.jsx`：路由、角色模型选择、共享交互状态。
- `src/pages/About.jsx` / `about.css`：项目介绍与互动模型。
- `src/scene/Character.jsx`：角色动画、嘴型、视线、点击与拖动。
- `src/pages/Portfolio.jsx`：Home 及保留的旧模板详情。
- `src/pages/Evolution.jsx` / `EvolutionTree.jsx`、`src/evolution.mjs`：路线、树结构、揭示与预览。
- `src/pages/Contact.jsx`：参赛支持页。
- `src/scene/World.jsx`、`src/world-collection.mjs`：场景与收集状态。
- `src/useNiulaiVoice.js`、`voice-player.mjs`、`voices.json`：语音选择、播放与素材清单。
- `src/i18n/`：界面语言。
- `src/hardware/` / `src/pages/Hardware.jsx`：未挂载的控制台实验，不等同正式接入。
- `public/`：模型、音频、图片与资源。`_headers` / `robots.txt` 仍禁止搜索引擎收录。
