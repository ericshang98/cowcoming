# JEV 软件宠物与标准动作

依据：Eric 本次要求优先于旧五动作展示限制；飞书最新只读同步仍为修订 212。继续既有隔离工作区，不联系其他会话、不激活硬件服务。

选择在通用 Harness 上增加完整软件宠物入口，保留原开发者实验室。直接改主站会把设备绑定流程带入首玩；另建第三套运行内核会重复已有协议。新入口复用标准动作数据，软件播放和硬件编译共享时间轴。

## 用户体验

- 默认原创程序牛，无 GLB/权重下载；六形态沿用已有性格与树，可切换体验。提供至少 16 项头部、手臂、身体互动动作，每项两种同义变体。
- 无 Key 可点动作预览；接入 JEV 后根据文字、当前形态、情绪和最近互动选择 action/emotion。预设反馈文字明确标注，不冒充 JEV 生成聊天。
- 模型设置表单：Cloudflare Account ID、JEV API Key，或显式 typed JEV 端点；独立可选进化评估 API Key、模型与 Chat Completions 地址。Key 仅当前本地服务内存，断开清除，静态版不提供 Key 输入。
- 显示本次 HTTP 决策耗时和置信度。模型失败不降级假装成功、不触发动作；停止和换形态取消在途结果。
- 动作试玩不计培养；真实 JEV 驱动并实际播完的软件互动可计入独立的软件培养会话。可选 LLM 每 N 轮读完整培养记录、保持或走一个直接后继。手动切换/重置使旧请求失效。没有评估配置时明确保持当前形态。
- 情绪是软件角色状态，不推断用户心理。原文档没有独立枚举，新增中性、好奇、开心、得意、委屈、困倦的可编辑示例；不得称为旧定义。

## 数据与硬件

动作包包含 ID、语义说明、变体及毫秒关键帧；逻辑轴为 headYaw/headPitch/headRoll/headLift、bodyYaw/bodyLean/bodyLift、leftArm/rightArm。归一化值 [-1,1]，角度映射与硬件标定分离。每条轨迹明确时长、回到中位、打断策略。

硬件配置声明 channel → joint、零位、正负方向、角度比例、位置范围、速度上限。编译器拒绝缺轴、非有限值、越界、超速；不静默裁剪或丢弃动作轴。示例配置只能 dry-run，执行需要显式已标定配置及驱动反馈。驱动接口 readState/writeFrame/stop 独立于串口厂商。一个回应 ID 关联软件动作、硬件轨迹和各自回执；发送完与传感器到位区别记录。

默认不连接硬件，页面可导入配置并导出标准动作/硬件轨迹，SDK 提供可测试的执行器和假设备示例。现有 BenBen 五动作驱动保留在开发者实验室，新增动作不直接下发给原机械臂。

## 验收

标准动作与同义变体、显式动作不替换、JEV 两问题请求/恶意输出拒绝、Key 不回传不持久化、取消/过期、软件培养去重/合法分支、硬件限位/速度/缺轴/停止。浏览器覆盖首玩、六形态、动作结束、Key 表单、JEV 固定响应、错误/停止、导出、移动布局和静态版。真实 JEV 效果与实机验收单独报告。
