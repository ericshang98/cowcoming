# IP Interaction Audio Implementation Plan

> Execute inline in this task with executing-plans; do not contact other tasks or agents.

**Goal:** Produce eight playable short interaction audio drafts, two per proposed character, with documented sources, action cues, and a local audition page.

**Architecture:** Keep draft assets and the audition page under `tools/ip-audio-preview/`, outside the production website build. Use a single audio player for interruption, keyboard L, mute and stop behavior. Source speech from short existing clips where accessible; preserve its natural delivery. Synthesize original nonverbal supporting effects with deterministic local signal processing as needed. Mark source authenticity and unresolved listening checks honestly.

**Tech Stack:** Python/NumPy, FFmpeg, browser audio, existing Node/Playwright tooling.
