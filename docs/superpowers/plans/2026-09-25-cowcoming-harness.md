实施中的明确修正：

- 模型同时指 AI 决策模型与角色 3D 资源，二者分别管理，默认不下载任何一种大文件。
- 不能对实机五动作传入任意强度或角度；BenBen profile 参数为空，示教轨迹由原控制器决定。
- 本包实际提供 GLB 实验室与本地 API，而不是只留下网站未来接入说明。
- 软件执行器模拟完成和动画播放分别记录；BenBen 回执后的动画是回放，不是同步运动或物理到位证据。
- 原网站已有公开仓库。本包另建轻量发布仓库，不携带原站 Git 历史和大素材，也不替原有 IP 授权。
- 使用独立 worktree 开发，保留原工作区的产品来源 JSON 和未提交模型文档。没有安装或重启现有设备服务。
