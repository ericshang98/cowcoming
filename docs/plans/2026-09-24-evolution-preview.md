# 图鉴缩略图与独立调试模式

依据：Eric 的截图及后续要求；已重新核对飞书修订 212。主分支已出现新的设备接线事实，本轮先合入，保留设备动作队列与网页调参。

- 图鉴六节点改用对应发布 GLB 渲染的缩略图；保持小牛→普通牛来→两分支的树。
- 图鉴选卡只打开独立 3D 预览，不派发成长 select、不更改 profile、不计轮；所有形态均可查看。
- WORK 左下角新增“调试模式”按钮；未绑定、离线也可打开。独立 dialog / Canvas / controller 支持拖动旋转、六形态切换、五动作试播和现有调参导入导出。
- 普通图鉴和调试界面共用模型预览。明确显示预览形态与实际当前形态；仅在线时提供单独的“设为当前形态”操作，沿用既有手动切换能力。
- 加载、失败、重试、关闭、键盘焦点和手机布局必须可用。调试结束释放播放器并回到原页面。正常成长和真实设备连接保持原逻辑。
- 预览及调参只影响网页；底层共享模型缓存但克隆骨架，避免污染真实角色。当前模型发布在已有 Pages 同源云端。
