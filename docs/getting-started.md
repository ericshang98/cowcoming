# 牛来使用指南

## 直接打开网页

访问 [牛来 WORK](https://cowcoming.world/?section=work)。普通网页体验无需下载源码或安装电脑 App。必须先用网页密钥绑定房间，并等待同一房间的本地设备上线，才会开放形态、进化设置、重置和实时面板。未连接时只显示角色预览和绑定引导。

## 选择形态与生长节奏

以下操作需要已绑定且设备在线。断线会关闭操作面板并暂停计轮和评估；切换房间会开始新的培养会话。

1. 左侧路线按钮切换显示的路线，点击具体形态节点才会改变当前形态。可以跨分支选择；手动选择后进入手动模式。
2. 左下角的进化设置打开“生长节奏”，可以选择手动或自动，设置每次评估间隔（默认 5 轮，可选 10 轮或输入 1–100），填写评估模型和网关地址。
3. 自动模式每达到设定轮数，独立评估模型读取本次培养的全部已完成对话，决定保持当前形态，或沿树前进一步。满 5 轮不保证进化；模型和网关未配置时不会进行真实自动评估。
4. 原暂停位置的重置按钮让牛来回到最初的小牛，清空本次培养会话和计数、作废旧评估；保留进化设置及 World 收藏。仙牛和暗黑牛到达终点后保持形态，由你决定何时重置。

正常页面不会把动作做成一排遥控按钮。用户输入会进入对话链路，JEV 在桌面宠物行为目录中选择一个动作，页面显示“观察 → 动作选择 → 动画/设备回执”；语言模型负责回复文字，不能越权生成新的动作。左下角 **调试模式** 提供按头部、躯干、前肢、腹部、尾巴和组合表达分组的动作试播与软件调参，调试播放不计进化、不驱动机械臂。实机只执行设备在 `supportedActions` 中声明的子集，BenBen 的五个旧动作只是其中一个 profile。

形态路线为：小牛 → 普通牛来 → 骚牛 → 仙牛，或小牛 → 普通牛来 → 硬牛 → 暗黑牛。目前可切换六种逻辑形态；每种形态都从同一套桌面宠物行为目录中选择适配的动作资源。网页会根据形态、事件和动作语义叠加已登记的软件表现变体（例如鞠躬、回望、摆动、沉思），丰富角色表现；实机执行集合由设备 `supportedActions` 决定，是否完成看设备回执。

保存进化设置会从零重新计轮，但保留本次培养的完整对话。设置保存在当前浏览器；刷新页面会开始新的培养会话。示例播放、鼠标互动、文本流的单个片段和重复事件都不计轮。接入方需要按 [进化运行合同](evolution-runtime.md) 提交完成的真实交互。

## 看实时画面、回复与动作

在 WORK 的连接引导中点击 **绑定我的牛来 / Bind my 牛来**，填入房间管理员提供的实时服务 URL 和 **Browser connection key**。设备端需要同时运行并使用该房间对应的设备密钥。

- **Vision / Action**：查看相机与动作信息；点击 **Start video** 请求视频。默认读取本地视觉程序；右上“编辑”也可选择电脑 / USB 摄像头、期望规格、镜像、旋转、比例和标注。配置与接入见 [本地视觉窗口](local-camera.md)。WebRTC 仅作为可选兼容模式。
- **Large Language Model**：查看设备程序发送的输入和流式回复。
- JEV 的动作选择与简短决策说明来自设备事件，机械臂是否完成以设备回执为准。

显示 **Waiting for device** 时，需要接入者启动对应的设备程序；仅网页连上房间不代表相机、JEV、LLM 和机械臂都已就绪。模拟示例带有明确标记，不控制真实机械臂。

## 接入自己的设备或模型

从公开的 [GitHub 仓库](https://github.com/ericshang98/cowcoming) 获取代码，按 [README 本地运行步骤](../README.md#本地运行) 启动网页。硬件开发者先阅读 [最新动作与进化交接](hardware-handoff.md)，再按 [设备 API 指南](live-device.md) 创建自己的房间、运行 Python 示例并替换适配器。

角色回复模型、JEV 和进化评估模型职责独立。进化设置中的 API 地址必须是实现 [评估网关合同](evolution-runtime.md#评估网关) 的服务；接入者在服务端配置提供商和密钥，不能仅填入一个厂商聊天接口就完成接入。使用者需要向自己的服务提供者取得可用的网关地址与模型 ID。

公开仓库不附带共享设备权限：网页操作者拿 `browserKey`，设备开发者拿 `deviceKey`，管理密钥和模型 API Key 留在自己的服务端或本机环境。创建房间和部署自己的服务所需步骤均在设备指南中。
