# 首页 IP 切换

2026-09-24。Eric 要求用导航第二个小图标替换旧简历入口，作为 IP 切换器；随后提供了峰哥、蜘蛛侠、奶龙、小黑龙四个模型包。本实现不把附件 README 中的旧控制台导入步骤当作网站改动指令。

## 用户体验

- 桌面导航第二个图标、手机顶部对应图标打开角色面板。可选择牛来、峰哥、蜘蛛侠、奶龙、小黑龙。
- 点选后先加载模型并验证动画，解码对应声音。期间继续显示原角色。成功后进入首页并整体切换；失败或 20 秒超时保留原角色，提供重试。关闭面板取消本次待完成的切换。
- 选择保存于 `cowcoming-ip`，刷新后恢复；未知 ID 或存储不可用回退到牛来。
- 左键点人物是短回应，L 是完整回应；拖动不触发点击。新回应替换旧回应，Esc 停止。打开选择面板、离开首页、暂停或隐藏页面会清理声音；静音时可继续无声动画。
- 牛来进化会话与 IP 选择独立。WORK、World、About 保留各自牛来功能；从这些页面选择 IP 会进入首页。没有将新角色套入缺少步行动画的 World。

## 真实模型与动作

| 角色 | 骨骼 | 左键 | L | 模型字节数 |
| --- | ---: | --- | --- | ---: |
| 峰哥 | 22 | nod + “毫无疑问” | reflect + 原参考录音短问答 | 5,599,520 |
| 蜘蛛侠 | 22 | wave + 射丝拟音 | bow + 动作拟音 | 5,466,788 |
| 奶龙 | 21 | tilt + 疑惑录音 | wave + 笑声 | 1,822,964 |
| 小黑龙 | 25 | tilt + 好奇短鸣 | wing_flap + 扑翼拟音 | 4,033,240 |

这些 GLB 均自包含，已核对实际二进制内的骨骼、动画、材质/贴图和交付哈希。没有执行附件脚本。小黑龙按本次实际交付命名，不继续把它断言为无牙仔。蜘蛛侠是镂空蹲姿雕塑，龙保留坐姿；现有招呼、俯身、歪头等动作是小幅动画，不声称已有射丝特效、倒挂、飞行或腾空。四个新模型均没有嘴型和步行，不创建假嘴型。

`src/ip-catalog.mjs` 绑定模型、名称、预览图、动画与声音。`useIpSelection` 和 `IpAssetProbe` 负责加载、失败、取消和提交选择；`useIpVoice` 提供一个可打断的媒体时钟；`Character` 按实际音频时间采样所选动画。人声保持原速，仅按录音长度调整身体动作进度。

## 素材与发布

运行文件在 `public/characters/<角色ID>/v1/`，随当前网站构建输出，运行时使用同源地址。Eric 已明确要求合并并发布。本版走既有 Pages 发布流程，这些运行资源随该版本一起上传，无需用户每次手工导入模型。若迁到独立资源存储，需修改资源根地址并验证跨域加载，不声称已经配置 R2。

模型来源是 Eric 直接提供的四个 ZIP；新增三包的哈希收据在 `public/characters/model-receipt.json`。峰哥 GLB SHA256 为 `0b028be4f3e4f7437206fed1b46f0fa7abb1ac583a53c8111461e30000f85c30`。原模型来源元数据：蜘蛛侠 Clean Studio / GentleDesign、奶龙“余味”、小黑龙 suare / GEM；附件均注明 Standard Digital File License，保留原标记，不改写成原创模型。

音频沿用已交付本地小样，来源、加工方式与未完成的人工听审见 [声音制作说明](../tools/ip-audio-preview/README.md)。奶龙/峰哥为公开参考录音剪辑，蜘蛛侠/小黑龙为拟音；代码许可证不替代这些角色素材的使用范围。本轮发布包括向现有公开仓库提交运行素材；发布成功以主域名版本和实际资源验证为准。
