# 首页 IP 切换

2026-09-24。Eric 要求用导航第二个小图标替换旧简历入口，作为 IP 切换器；随后提供了峰哥、蜘蛛侠、奶龙、小黑龙四个模型包。本实现不把附件 README 中的旧控制台导入步骤当作网站改动指令。

## 用户体验

- 桌面导航第二个图标、手机顶部对应图标在其下方打开小浮层（约 306 × 92 px），用一排五个真实模型渲染的圆头像选择牛来、峰哥、蜘蛛侠、奶龙、小黑龙。没有大标题、介绍列表或全屏遮罩；支持方向键、Escape、点击外部关闭和返回触发按钮。
- 点选后先加载模型并验证动画，解码对应声音。期间继续显示原角色。成功后进入首页并整体切换；失败或 20 秒超时保留原角色，提供重试。关闭面板取消本次待完成的切换。
- 选择保存于 `cowcoming-ip`，刷新后恢复；未知 ID 或存储不可用回退到牛来。
- 左键点人物是短回应，L 是完整回应；拖动不触发点击。新回应替换旧回应，Esc 停止。打开选择面板、离开首页、暂停或隐藏页面会清理声音；静音时可继续无声动画。
- 牛来进化会话与 IP 选择独立。WORK、World、About 保留各自牛来功能；从这些页面选择 IP 会进入首页。没有将新角色套入缺少步行动画的 World。

## 真实模型与动作

| 峰哥 | 22 | 点头两下、身体前倾 + “毫无疑问” | 抬起双臂摊手、转头接话 + 原参考录音短问答 | 5,599,520 |
| 蜘蛛侠 | 22 | 伸腕、躯干转向、蛛丝线条 + 射丝拟音 | 下压蓄力、小幅跃起、落地回稳 + 动作拟音 | 5,466,788 |

这些 GLB 均自包含，已核对实际二进制内的骨骼、动画、材质/贴图和交付哈希。没有执行附件脚本。小黑龙按本次实际交付命名。蜘蛛侠是镂空蹲姿雕塑，没有独立手指骨骼；四个新模型没有嘴型和步行，不创建假嘴型。

Eric 在第一版上线后指出动作不明显。实查原始预设多数仅转动头部，蜘蛛侠手部和龙翼只转数度；旧验证只证明动作和声音进入播放状态，没有验收动作本身的可见幅度。本次 `src/scene/ip-motion.mjs` 基于真实绑定姿势重新编排八套多关节动作，保留源 GLB 字节不变。以音频的归一化进度采样，分别包含起势、主动作和回稳；中断时 180 ms 混合回待机。蜘蛛侠短动作增加腕部随动蛛丝；手机按模型宽度留动作空间，不再沿用牛来大幅裁切和渐隐身体的画面。

奶龙的源蒙皮将部分肚皮分配给手臂，抬手会拉扯腹部。`src/scene/ip-skin.mjs` 仅克隆运行实例的 geometry，将臂部范围外的权重归回躯干，原 GLB 不改；真实网格测试验证绑定姿势不变、抬手时肚皮位移保持在 0.15 模型单位以内（原权重约 0.41）。动作幅度按实际模型限制调整。

`src/ip-catalog.mjs` 绑定名称、预览、动画与声音。`useIpSelection` / `IpAssetProbe` 先核验模型和声音再切换；`useIpVoice` 提供可打断的媒体时钟。人声保持原速，仅调整身体动作进度。`tools/ip-portraits/render.mjs` 从五个实际 GLB 的头部蒙皮区域渲染圆头像使用的透明 PNG，含牛来；可用 `node scripts/render-ip-portraits.cjs` 在开发服务下重建。

## 素材与发布

运行文件在 `public/characters/<角色ID>/v1/`，随当前网站构建输出，运行时使用同源地址。Eric 已明确要求合并并发布。本版走既有 Pages 发布流程，这些运行资源随该版本一起上传，无需用户每次手工导入模型。若迁到独立资源存储，需修改资源根地址并验证跨域加载，不声称已经配置 R2。

模型来源是 Eric 直接提供的四个 ZIP；新增三包的哈希收据在 `public/characters/model-receipt.json`。峰哥 GLB SHA256 为 `0b028be4f3e4f7437206fed1b46f0fa7abb1ac583a53c8111461e30000f85c30`。原模型来源元数据：蜘蛛侠 Clean Studio / GentleDesign、奶龙“余味”、小黑龙 suare / GEM；附件均注明 Standard Digital File License，保留原标记，不改写成原创模型。

音频沿用已交付本地小样，来源、加工方式与未完成的人工听审见 [声音制作说明](../tools/ip-audio-preview/README.md)。奶龙/峰哥为公开参考录音剪辑，蜘蛛侠/小黑龙为拟音；代码许可证不替代这些角色素材的使用范围。本轮发布包括向现有公开仓库提交运行素材；发布成功以主域名版本和实际资源验证为准。
