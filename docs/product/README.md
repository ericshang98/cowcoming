# 产品文档入口

唯一产品真源：[牛来 / 多 IP 软硬件互动系统产品文档](https://uxl9fceo481.feishu.cn/wiki/Ehc9w5bs1ic2gEkwZjCc8Eo1nmb)。仓库的 [spec.md](spec.md) 是便于跨设备、新会话和离线阅读的完整快照，修订号、抓取时间和内容哈希见 [source.json](source.json)。

每次开发先读快照并核对飞书最新内容。快照不是自动实时同步；产品文档更新后，将快照和相关实现一起更新、提交。读取失败不覆盖已有快照，不把失败或登录页当成产品正文。

## 更新快照

已安装并授权 `lark-cli` 的设备可执行：

```sh
npm run docs:sync
```

默认使用已授权的 bot 身份；若设备只有用户身份且具备文档读取权限，可运行 `LARK_IDENTITY=user npm run docs:sync`。此命令只读取文档、更新本地快照和来源元数据，不修改飞书文档、不发送消息。

无需为正常开发安装 CLI。没有文档权限时先用仓库快照，并说明当前修订号；可以通过浏览器打开原链接核对。不要复制其他设备的授权文件或把登录数据提交到仓库。
